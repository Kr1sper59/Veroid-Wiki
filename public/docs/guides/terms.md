# Терминология хостинга

На хостинге **Veroid** используется панель **Pterodactyl**. Ниже собраны термины, которые часто встречаются в гайдах и настройках.

## Основные понятия

- **Узел (нода)** - физический или виртуальный сервер, на котором расположены ваши игровые серверы. Для лучшей работы прокси и игровых серверов рекомендуется держать их на одной ноде и использовать локальный адрес `172.18.0.1` для связи.
- **Ядро** - файл запуска (`server.jar` или аналог), который определяет, как работает ваш сервер. Бывают ядра для плагинов (Paper, Purpur), для прокси (Velocity, Waterfall) и для модов (Forge, Fabric, Quilt).
- **Яйцо / экземпляр** - установщик/конфигурация для запуска сервера в панели Pterodactyl. Это не готовый контейнер, а набор настроек (ядро, версия, ресурсы), на основе которых панель собирает сервер. После установки вы получаете рабочий экземпляр с файлами и процессом.
- **SFTP** - защищённый протокол передачи файлов. Используется для загрузки ядер, плагинов и конфигов на сервер. Данные для подключения находятся во вкладке **Настройки** панели.
- **Прокси** - промежуточный сервер, объединяющий несколько игровых серверов в одну сеть. Игроки подключаются к прокси, а он перенаправляет их на нужный игровой сервер.
- **Биллинг / панель** - система оплаты и управления серверами.

## Сетевые термины

- **IP-адрес сервера** - адрес, по которому игроки подключаются (например, `bullet.veroid.ru` или `123.45.67.89`). Не включает порт.
- **Порт** - числовой идентификатор для подключения. Стандартный порт Minecraft - **25565**.
- **Дополнительный порт** - порт, открытый в панели для специфических задач (например, голосовой чат на `24454` или прокси).
- **172.18.0.1** - локальный адрес докера. Если прокси и игровые серверы стоят на одной ноде, для связи между ними лучше использовать именно его.
- **Forced-hosts / поддомены** - настройка, при которой игроки подключаются по разным адресам (`lobby.example.com`, `main.example.com`) и попадают на разные серверы сети.
