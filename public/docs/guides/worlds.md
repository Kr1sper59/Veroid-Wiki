# Миры

Управление мирами - одна из базовых задач при настройке сервера.

## Структура миров

По умолчанию сервер создает три мира:

| Папка | Мир |
|---|---|
| `world/` | Обычный мир (Overworld) |
| `world_nether/` | Незер (Nether) |
| `world_the_end/` | Край (End) |

> ⚠️ Названия папок могут отличаться в зависимости от ядра. Например, на Forge миры Незера и Края находятся внутри папки `world/`.

## Сброс мира

Если вы хотите сгенерировать мир заново:

1. Остановите сервер.
2. Удалите папки миров (`world/`, `world_nether/`, `world_the_end/`).
3. При необходимости измените сид в [server.properties](/guides/server.properties) (параметр `level-seed`).
4. Запустите сервер - мир сгенерируется заново.

> ⚠️ Перед удалением мира сделайте [бэкап](/guides/backups), если хотите сохранить возможность вернуться.

## Загрузка своей карты

Чтобы загрузить готовую карту (из одиночной игры или скачанную):

1. Остановите сервер.
2. Удалите текущую папку `world/`.
3. Загрузите вашу карту на сервер через [SFTP](/guides/sftp) и переименуйте её в `world` (или в имя, указанное в `level-name` в `server.properties`).
4. Убедитесь, что внутри папки находятся файлы мира (`level.dat`, папка `region/` и т.д.), а не ещё одна вложенная папка.
5. Запустите сервер.

## Мультимиры

Для создания нескольких миров на одном сервере используются плагины:

- [Multiverse-Core](https://modrinth.com/plugin/multiverse-core) - самый популярный плагин для управления мирами. Позволяет создавать, удалять и телепортироваться между мирами.
- [MyWorlds](https://www.spigotmc.org/resources/myworlds.39594/) - альтернатива Multiverse.

### Базовые команды Multiverse

| Команда | Описание |
|---|---|
| `/mv create <имя> <тип>` | Создать новый мир |
| `/mv tp <мир>` | Телепортироваться в мир |
| `/mv list` | Список всех миров |
| `/mv delete <мир>` | Удалить мир |
| `/mv confirm` | Подтвердить удаление |
