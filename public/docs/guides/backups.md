# Бэкапы

Резервные копии позволяют восстановить данные после ошибки или неудачного обновления. Рекомендуется делать бэкап перед любыми крупными изменениями.

## Бэкап через панель

1. Перейдите во вкладку **Бэкапы** в панели управления.
2. Нажмите **Создать бэкап**.
3. Дождитесь завершения создания бэкапа.

Готово! Бэкап сохранен в панели и его можно восстановить в любой момент из этой же вкладки.

## Бэкап через SFTP

Если вы хотите сохранить файлы на свой компьютер:

1. Подключитесь к серверу по [SFTP](/guides/sftp).
2. Скачайте нужные папки и файлы.

### Что важно сохранять

| Папка / файл | Описание |
|---|---|
| `world/`, `world_nether/`, `world_the_end/` | Файлы миров |
| `plugins/` | Плагины и их конфиги |
| `mods/` | Моды (для Forge/Fabric серверов) |
| `config/` | Конфигурации модов |
| `server.properties` | Основные настройки сервера |
| `*.yml` / `*.toml` | Конфиги ядра (paper-global.yml, velocity.toml и т.д.) |

## Восстановление из бэкапа

### Через панель
1. Перейдите во вкладку **Бэкапы**.
2. Найдите нужный бэкап и нажмите **Восстановить**.
3. Дождитесь завершения восстановления.

### Через SFTP
1. Остановите сервер.
2. Удалите текущие файлы, которые хотите заменить.
3. Загрузите файлы из бэкапа через [SFTP](/guides/sftp).
4. Запустите сервер.

> ⚠️ При восстановлении через SFTP не загружайте файлы поверх существующих без удаления - это может привести к конфликтам конфигов.
