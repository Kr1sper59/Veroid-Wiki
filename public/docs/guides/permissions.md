# Права (Permissions)

Система прав позволяет настроить, какие команды и функции доступны каждому игроку или группе игроков.

## Зачем нужны права

По умолчанию у обычных игроков минимальные права, а у операторов (`/op`) - полный доступ ко всему. Плагины прав позволяют создавать группы (Admin, Moderator, Helper, VIP и т.д.) и назначать конкретные разрешения каждой из них.

## LuckPerms

[LuckPerms](https://luckperms.net/) - самый популярный и рекомендуемый плагин для управления правами.

Скачать: [luckperms.net](https://luckperms.net/download)

### Установка

1. Скачайте версию LuckPerms для вашего [ядра](/guides/core) (Bukkit/Paper, Fabric, Forge и т.д.).
2. Загрузите файл в папку `plugins/` (или `mods/` для модовых серверов).
3. Перезапустите сервер.

### Основные команды

| Команда | Описание |
|---|---|
| `/lp editor` | Открыть веб-редактор прав |
| `/lp creategroup <группа>` | Создать новую группу |
| `/lp listgroups` | Показать список всех групп |
| `/lp group <группа> permission set <право> true` | Выдать право группе |
| `/lp user <ник> parent set <группа>` | Назначить игрока в группу |
| `/lp user <ник> permission set <право> true` | Выдать право конкретному игроку |
| `/lp group <группа> meta setprefix "<префикс>"` | Установить префикс для группы |

### Веб-редактор

Команда `/lp editor` открывает удобный веб-интерфейс для просмотра и редактирования всех групп и прав. Рекомендуется использовать именно его для настройки.

> ⚠️ Для отображения префиксов в чате и табе нужен дополнительный плагин, например [TAB](https://modrinth.com/plugin/tab-was-taken).

## Где найти названия прав

Права для каждого плагина обычно указаны на странице плагина (Modrinth, SpigotMC) или в его документации.
