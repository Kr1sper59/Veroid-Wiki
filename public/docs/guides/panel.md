# Как начать работу с панелью

Хостинг **Veroid** работает на панели **Pterodactyl**. Ниже описаны базовые шаги после создания сервера.

## Вкладки панели

| Вкладка | Описание |
|---|---|
| **Запуск** | Выбор ядра (`server.jar`), версии игры и Java. Также здесь указывается команда запуска. |
| **Настройки** | Переустановка сервера, смена версии, удаление файлов, привязка Discord к биллингу. |
| **Порты** | Открытие дополнительных портов для голосового чата, прокси или других задач. |
| **Файлы** | Веб-менеджер файлов или подключение по **SFTP** (данные в настройках). |
| **Консоль** | Командная строка сервера, выполнение команд (`/op`, `/whitelist`, `/stop` и т.д.). |

> ⚠️ Перед сменой версии или переустановкой рекомендуется удалить файлы сервера или сделать бэкап через SFTP.

## Создание сервера

1. Выберите тариф в биллинге и укажите **узел (ноду)**, где будет размещён сервер.
2. Укажите версию Minecraft и ядро (Paper, Velocity, Forge и т.д.).
3. После создания сервер появится в панели с вкладками выше.

> ⚠️ Одна нода - обязательное условие для связки Velocity / Waterfall. Для связи используйте адрес докера: `172.18.0.1`.

## Привязка Discord к биллингу

Это нужно для поддержки, авторизации и получения уведомлений.

1. Перейдите на сайт [dash.veroid.net/home](https://dash.veroid.net/home).
2. Откройте **Профиль** → нажмите **Войти через Discord**.
3. Подтвердите привязку в настройках профиля.

Подробный гайд с скриншотами - в разделе [коммюнити](community/discord).

## Быстрые команды для начала

После запуска сервера в консоли можно:

- `op <ник>` - выдать операторские права.
- `whitelist add <ник>` - добавить в белый список.
- `stop` - остановить сервер.
- `save-off` / `save-on` - временно отключить/включить сохранение мира.

Если нужна помощь с настройкой ядра или портов - смотрите разделы [ядра](guides/core), [SFTP](guides/sftp) или [прокси](guides/proxy).
