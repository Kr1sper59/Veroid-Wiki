# Частые вопросы и ошибки

Здесь собраны типичные проблемы и способы их решения.

## Сервер не запускается

### Error: Unable to access jarfile server.jar
Файл ядра отсутствует или имеет неправильное имя.

**Решение:** убедитесь, что файл ядра называется `server.jar` (или совпадает с именем, указанным во вкладке **Запуск**). Загрузите ядро заново при необходимости.

### Unsupported Java version
Версия Java не соответствует версии Minecraft.

**Решение:** выберите правильную версию Java согласно [таблице](/guides/version#таблица-выбора-версии-java).

### Address already in use
Порт уже занят другим процессом.

**Решение:** убедитесь, что вы используете порт, выделенный вашему серверу в панели. Не меняйте `server-port` в `server.properties` на произвольный.

## Не могу подключиться к серверу

### Connection timed out
Сервер недоступен или порт заблокирован.

**Решение:**
1. Проверьте, запущен ли сервер (консоль в панели).
2. Убедитесь, что вы используете правильный IP и порт.
3. Если вы в России и сервер на европейском узле - попробуйте [Zapret](/community/zapret).

### Outdated server / Outdated client
Версии клиента и сервера не совпадают.

**Решение:** обновите клиент или сервер до одной версии. Для поддержки нескольких версий клиентов используйте плагин [ViaVersion](https://modrinth.com/plugin/viaversion).

### Failed to verify username
Сервер работает в `online-mode=true`, а вы используете нелицензионный клиент (или наоборот).

**Решение:** проверьте параметр `online-mode` в [server.properties](/guides/server.properties). Установите `false` для нелицензионных клиентов.

## Плагин не работает

### Плагин не загружается
- Проверьте совместимость плагина с вашим [ядром](/guides/core) и версией Minecraft.
- Проверьте консоль на наличие ошибок при запуске - часто плагину не хватает зависимости.
- Убедитесь, что файл `.jar` находится в папке `plugins/`.

### Команды плагина не работают
- Убедитесь, что у вас есть [права](/guides/permissions) на использование команды.
- Попробуйте выполнить команду из консоли - если там работает, проблема в правах.

## Сервер лагает

1. Установите [Spark](/guides/spark) и выполните `/spark profiler open` для диагностики.
2. Проверьте потребление ресурсов в панели - возможно, не хватает ОЗУ.
3. Ознакомьтесь с [гайдом по оптимизации](/community/optimization).

## Мир не сохраняется / данные теряются

- Не выключайте сервер кнопкой **Убить процесс** - используйте **Стоп** или команду `stop`.
- Убедитесь, что автосохранение не отключено (`save-on` в консоли).
- Делайте регулярные [бэкапы](/guides/backups).

## Как дать себе права администратора

Выполните в консоли сервера (не в игровом чате):

```
op <ваш_ник>
```

Для более гибкой настройки используйте систему [прав](/guides/permissions).
