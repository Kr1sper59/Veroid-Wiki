# Ресурс-пак

Серверный ресурс-пак позволяет изменить текстуры, звуки и модели у всех игроков на сервере без ручной установки.

## Подготовка

1. Создайте или скачайте ресурс-пак (файл `.zip`).
2. Загрузите его на хостинг файлов с прямой ссылкой на скачивание. Подходят:
   - [mc-packs.net](https://mc-packs.net/) - бесплатный хостинг специально для ресурс-паков Minecraft.
   - [GitHub Releases](https://github.com/) - загрузите `.zip` как релиз в своем репозитории.
   - Любой файлообменник с поддержкой прямых ссылок.

> ⚠️ Ссылка должна вести напрямую к файлу `.zip`, а не на страницу скачивания.

## Настройка на сервере

Откройте файл [server.properties](/guides/server.properties) и укажите следующие параметры:

```properties
# Прямая ссылка на ресурс-пак
resource-pack=https://example.com/resourcepack.zip

# SHA1 хеш файла (для проверки целостности)
resource-pack-sha1=

# Сообщение при запросе ресурс-пака (необязательно)
resource-pack-prompt=Пожалуйста, примите ресурс-пак для лучшего опыта игры!

# Требовать ресурс-пак (игрок не сможет зайти без него)
require-resource-pack=false
```

### Получение SHA1 хеша

SHA1 хеш нужен, чтобы клиент проверил, что файл скачался правильно.

**Windows (PowerShell):**
```powershell
Get-FileHash resourcepack.zip -Algorithm SHA1
```

**Linux/macOS:**
```bash
sha1sum resourcepack.zip
```

> ⚠️ При обновлении ресурс-пака не забудьте обновить ссылку и SHA1 хеш в `server.properties`.
